Models propose. A small guard decides.

An experimental operating system for running untrusted AI agents. The agent can think and ask for anything it likes, but it can act on the world only through a small, deterministic guard, and the guard is specified precisely enough to be checked.

The aim is to verify the envelope around the model, not the model itself.

In progress · unaudited research

The idea

Every action goes through the guard

An agent holds no keys. It reaches the model through a proxy that holds the key, and reaches tools only through the guard. Each call is checked against a manifest the tool declares and a policy the person wrote.

The record is written first

Each decision is appended to a tamper-evident, hash-chained audit log before the action happens, so the record is made before the deed, not after it.

Risk sets who decides

Safe, reversible actions run on their own. Others are logged and surfaced, held for a person's approval, or, for the highest stakes, need two independent confirmations. Reversible actions take a restore point first.

A display the agent cannot draw on

Approvals are shown by a trusted display that composes its own screen. Anything an agent influenced is visibly marked as untrusted, so an agent's own text is not mistaken for the system's.

Why it can be checked

The guard's core rules are written as TLA+ models and model-checked: how authority is delegated and revoked, and how approval tiers, independent channels and budgets behave. The Rust implementation is replayed against the models' state graphs, so the code is tested against the specification, not only against itself.

The longer-term direction is to run the same small guard on a verified microkernel, so isolation rests on something far smaller than a general-purpose operating system.

What it is not

  • Not a claim that agents behave correctly or are aligned.
  • Not a security product, and not audited. No part of it has been proven.
  • Not a finished operating system. Today it runs as a set of services on Linux, behind a text-mode trusted display.
